# Kirchhoff's Law 3D Simulation Lab

An interactive laboratory application to assemble DC circuits, verify Kirchhoff's Current Law (KCL) and Kirchhoff's Voltage Law (KVL), and automatically construct animated 3D circuits from uploaded 2D schematic images.

## Features
- **Landing Hero**: Blueprint schematics and direct user sign-in portal.
- **Learn Section**: Comprehensive review of KCL, KVL, equations, and comparison tables.
- **3D Workbench**: Three.js-powered physical circuit manipulation, wiring, and live particle current animations.
- **2D-to-3D Image Converter**: Upload circuit diagrams or photographs to generate working 3D topologies.
