# Submission: Kirchhoff's Law 3D Virtual Lab

## Project Overview
Interactive 3D DC circuit simulation laboratory designed to verify Kirchhoff's Current Law (KCL) and Kirchhoff's Voltage Law (KVL). Features an AI-assisted 2D-to-3D circuit generator that translates diagrams into interactive 3D simulations.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- 3D Engine: Three.js (r128), OrbitControls
- Math & Simulation: Real-time DC nodal mesh solver
