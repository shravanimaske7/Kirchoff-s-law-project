# Agent Directives & Capabilities

- **3D Circuit Generator Agent**: Translates 2D wiring images and schematics into 3D coordinate meshes with gold terminal interconnects[cite: 4, 10].
- **Kirchhoff Simulation Agent**: Solves nodal equations ($\Sigma I = 0$) and loop voltages ($\Sigma V = 0$) dynamically on each parameter update[cite: 2, 3].
